# Detox Primavera

Material de referencia recibido el 26 de septiembre de 2026.

## Documentos

- `guia-detox-primavera.pdf`: plan alimentario, recetas, métodos de cocción y fichas de ingredientes.
- `como-prepararse-para-el-detox.pdf`: preparación previa, reducción de cafeína y lista de compras.
- `RESUMEN-OPERATIVO.md`: síntesis estructurada de fases, alimentos permitidos y restringidos.
- `INFO-TALLER-ISA-CAPARRA.md`: enlaces a Google Meet (fechas en vivo), grabaciones de YouTube, grupo de WhatsApp y contacto de Isa Caparra.
- `LISTA-DE-COMPRAS.md`: lista de compras completa organizada por comercio (verdulería, dietética, panadería, etc.) y por tipo de alimento/suplemento.

## Punto de partida

1. Leer primero `como-prepararse-para-el-detox.pdf`.
2. Elegir si se hará o no el inicio opcional de 1 a 3 días con manzana y arroz integral.
3. Usar `guia-detox-primavera.pdf` como menú y recetario para los días posteriores.

Este material contiene indicaciones alimentarias, suplementos y plantas. Si hay medicación, embarazo/lactancia, enfermedades crónicas, antecedentes digestivos o trastornos de la conducta alimentaria, conviene validarlo con un profesional de salud antes de empezar.
